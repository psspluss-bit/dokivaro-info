Bundled license and copyright records

Dokivaro Pro 0.9.8 and later provide an offline inventory of npm license texts and a separate release-bound inventory of Android runtime components. The Android list is generated from Gradle's actual releaseRuntimeClasspath and includes resolved component versions, SHA-256 checksums for binary artifacts, license evidence, and original LICENSE/NOTICE files found inside the published dependencies. The full Apache License 2.0 text is bundled with the app.

In the app, open Settings → Open-source licenses to inspect the original third-party texts. This website lists the main components only, not every transitive library.

Absence of a NOTICE file in a compiled library archive does not prove that the upstream source project contains no additional attribution material. Some npm build dependencies also lack a separate license file in the automatic inventory. This documentation is a technical license audit, not a legal sign-off.
